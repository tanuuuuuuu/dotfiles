# eli — Explain Like I'm 5 / 15 / 25

トピック: $ARGUMENTS

1つの HTML アーティファクトに3レベルの解説を入れ、タブで切り替えられるようにする。
各タブの中身の作り方（構成・文体・図の様式）は規定しない。以下の一行だけを指針に、
トピックに合った最良の説明をレベルごとに考える。

- **ELI5**: このトピックを何も知らない人向けに。大きな図と少ない言葉で
- **ELI15**: 実際の仕組みを理解したい人向けに。平易だが正確に
- **ELI25**: ELI15 を読み終えて「もっと詳しく」と言った人向けに。トレードオフや制約まで

深さは常に隣のタブからの相対距離で決める（「専門家水準」のような絶対水準に
合わせない）。どのレベルにも嘘を書かない。単純化はしても、上のレベルを読んだとき
矛盾に気づくような説明は理解を壊す。公開前に技術的な主張（用語・数値・手順・
コード例）を読み返し、確信が持てないものは書き直すか削る。

## 作成手順

1. アーティファクトを書く前に `artifact-design` スキルを読み込む。図（インライン
   SVG）を描く前に `artifact-diagramming` スキルを読み込む。外部ライブラリは使えない
2. HTML 要件:
   - タブスイッチャー（ELI5 / ELI15 / ELI25）は `position: sticky` で画面上部に追従させる
   - 選択タブは localStorage に記憶する（読み書きとも try/catch 必須。初期値は ELI5。
     キーは `eli-<トピックスラッグ>-tab` のようにトピック別にする）
   - ライト/ダーク両テーマ対応
3. Artifact として公開し、URL をユーザーに返す。favicon はトピックに合った絵文字
