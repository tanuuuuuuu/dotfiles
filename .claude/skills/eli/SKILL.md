# eli — Explain Like I'm 5 / 15 / 35

トピック: $ARGUMENTS

1つの HTML アーティファクトに3レベルの解説を入れ、タブで切り替えられるようにする。
読者は理解度に応じてレベルを行き来するので、3レベルで同じ骨格（例: 入力 → 処理 → 出力）を
段階的に詳細化し、タブを切り替えたときに対応関係が追えるようにする。

## レベル定義

| タブ | 想定読者 | 文章 | 図 |
|------|----------|------|-----|
| 5歳 | 前提知識ゼロ | 比喩だけで語る。専門用語禁止。文は最小限、図が主役 | 大きな比喩イラスト |
| 15歳 | 高校生 | 実際の仕組みを簡略化。基本用語は初出で一言定義してから使う | 簡略フロー図 |
| 35歳 | 同業の専門家 | 正確な用語で書く。トレードオフ・エッジケース・制約まで踏み込む | 正確なアーキテクチャ図・シーケンス図 |

5歳タブに嘘を書かない。「単純化した本当のこと」と「かわいい嘘」は別物で、
上のレベルを読んだとき矛盾に気づくような比喩は理解を壊す。

## 作成手順

1. アーティファクトを書く前に `artifact-design` スキルを読み込む
2. トピックの骨格（3〜5個の構成要素）を決め、それを3レベルで段階的に詳細化する
3. 図は各レベル最低2つ（5歳タブも含む）、インライン SVG で描く。描く前に
   `artifact-diagramming` スキルを読み込む。外部ライブラリは使えない
4. HTML 要件:
   - タブスイッチャー（5歳 / 15歳 / 35歳）は `position: sticky` で画面上部に追従させる
   - 選択タブは localStorage に記憶する（読み書きとも try/catch 必須。初期値は 5歳。
     キーは `eli-<トピックスラッグ>-tab` のようにトピック別にする）
   - ライト/ダーク両テーマ対応
5. Artifact として公開し、URL をユーザーに返す。favicon はトピックに合った絵文字
